    User Guide

    Peekee shows you what is inside a file before you open it. Select a file, press Space, and a preview appears beside your work. Press Space again and it is gone.

    To find something in here, use the search box in the bar at the top: four letters or more. It lists the sections your word appears in and marks each place on the page; the ✕ clears it. Once you are well down the page, an arrow at the bottom right takes you back to the top.

    01In a hurry to get started?

    1. Install Peekee and start it. Its icon appears in the tray, next to the clock. If you cannot see it, look under the ^ arrow with the other hidden tray icons.
    2. Open a folder in File Explorer, or look at your Desktop, and click a file once to select it.
    3. Press Space. The preview opens beside your work. Your keyboard stays in the window you were in.
    4. Press Space or Esc to close it.

    That is all. There is nothing to set up. To use another key than Space, or to change how big the preview is, see Settings.

    02Keys and mouse

    Peekee watches the window you are working in. It only reacts when a file list has the keyboard focus, so typing in a search box or renaming a file works as usual.

    Space
    Opens the preview of the selected file, and closes it again. If nothing is selected, or Peekee cannot preview where you are, the key goes to the window as usual. You can choose Ctrl + Space or Shift + Space instead in Settings.
    Esc
    Closes the preview. This works whichever key you chose to open it.
    Arrow keys, Home, End, Page Up and Page Down
    Move the selection in the window behind, as they always do, and the preview follows to the new file. You do not have to close it first.
    Left and Right on a file with pages
    When the preview shows a file with several pages, such as a TIFF, an Illustrator file or a PDF drawn by Windows, Right turns to the next page and Left to the previous one. On the last page, Right goes back to the window behind, so in an Icons view it moves on to the next file; on the first page, Left does the same. PDFs shown by Edge and Office files shown by Office keep their own scrolling: use the mouse wheel there.
    Several files selected
    The preview shows the focused file, and the header says how many are selected.
    Dragging an edge
    Drag any edge of the preview to resize it. Peekee remembers the size unless you turn that off in Settings.
    Mouse wheel
    Scrolls text and tables. On an image it zooms. On a PDF drawn by Windows it scrolls the page, and at the end of a page it moves to the next one (Ctrl and the wheel zoom).

    The header buttons

    The name of the file is on the left of the header, with the buttons on the right. Hover over a button to see its name.

    ButtonWhat it does
    OpenOpens the file in the program Windows uses for it.
    PinNot available yet. It is greyed out.
    CopyCopies what you are looking at. A text file (up to the largest size set in Settings) is copied as text, a picture as a picture (a PDF or multi-page TIFF copies the page showing), and anything else, including a folder, as the file itself, so Paste in File Explorer copies it.
    Copy pathCopies the full path of the file as text.
    CloseCloses the preview.
    Previous page and Next pageAppear only for files with pages, such as a PDF or a TIFF with several pages. Left and Right do the same.
    Fit page, Fit width, 100 percent, Zoom out and Zoom inAppear for a PDF drawn by Windows. Zoom steps are 25, 50, 75, 100, 125, 150, 200, 300 and 400 percent. A button that would change nothing is greyed out.

    Open, Copy and Copy path are greyed out when no file is showing, and Copy is also greyed out for an item that could not be read.

    03Where Peekee works

    File Explorer
    Every view: details, list, icons and tiles. Peekee reads the selection from Explorer and never changes anything.
    The Desktop
    Select an icon on the Desktop and press the key.
    Open and Save dialogs
    Peekee also works inside the Open and Save dialogs of other programs, so you can check a file before you pick it. Turn this off in Settings if a program does not like it.

    Some older programs use an old style of file dialog.

    Peekee cannot see which file is selected in those, so it shows nothing there, and the key goes back to the dialog as usual. Most current programs use the standard dialog, which works.

    04What Peekee can show

    A preview opens at once and reads the file without changing it.

    Images
    PNG, JPG, GIF, BMP, WebP, TIFF and ICO, plus HEIC and AVIF where Windows has the codec installed. Amiga IFF pictures (.iff, .ilbm, .lbm, .ham6, .ham8, .acbm, .rgb8, .rgbn, including HAM and EHB, pictures with a palette for every line, Atari ST pictures, the true-colour RGB8 and RGBN kinds, and the PC PBM kind; a file that is cut short shows the part that is there) are drawn by Peekee itself; the footer says how many colours they use. Their pixel shape is not corrected, so a low-resolution Amiga picture can look narrower than it did on the Amiga. Photoshop files (.psd and the large-document .psb) show the merged picture saved in the file, in RGB, CMYK, gray, indexed or black and white at 8 or 16 bits; layers are not shown. If the file was saved without that picture, is over 16 megapixels or is in an unsupported mode, Peekee shows the small preview picture stored in the file when there is one, and the footer says "thumbnail only". A GIF plays, and the footer says how many frames it has, how fast it runs and how often it plays. A TIFF with several pages shows one page at a time, with page buttons in the header. The wheel zooms, dragging pans, and a double click fits the image to the window again. In Settings you choose whether images open fitted to the window or at 100 percent, and what shows behind them.
    Text and code
    Plain text, logs, configuration files and source code, in a monospace font with line numbers. Long lines scroll sideways instead of wrapping. A file larger than the limit in Settings (2 MB to start with) shows its first part, with a note in the footer.
    CSV and TSV
    A table of the first 5,000 rows. The first row becomes the column headers when the file seems to have one. Otherwise the columns are lettered.
    JSON
    Laid out with indents so it is easy to read. A file that is not valid JSON shows as plain text.
    Markdown
    Shown as a formatted document with headings, lists, tables, code and the images that sit beside the file. Links are drawn as links but cannot be clicked.
    SVG
    Drawn and fitted to the window. It does not zoom or pan, and a drawing that uses features Peekee does not support, such as CSS classes, may look different from the way a browser shows it.
    Fonts
    TTF, OTF and TTC files show as a type specimen: the family and style name, the alphabet, the digits and a sentence at three sizes. The font is not installed.
    Folders
    How many items are inside and how big they are in all (counted in the background), with the five newest items.
    Archives
    The contents are listed without unpacking anything: zip, RAR, 7z, ISO, tar (also tar.gz, tgz, tar.bz2, tbz2, tar.xz and txz), gz, bz2, xz, CAB and LHA (lzh, lha). Folders inside show as a tree: click a folder row to open or close it. Name, Size and Modified have their own columns. An archive with a password, or one that is damaged, shows the information card instead.
    WordPerfect
    WordPerfect documents (.wpd, .wp, .wp5, .wp6 and .wp7, from WordPerfect 5 and later) show their text only, in the same plain view as a text file, and the footer gives the word count. Fonts, layout, tables, pictures and footnotes are not shown, and a few special characters may appear as a question mark. A file that is password protected, or from which no text can be read, shows the information card.
    Adobe Illustrator
    An .ai or .ait file saved with the PDF compatible option (the default for many years) shows as a PDF does, one page at a time, with the page buttons and zoom buttons. Peekee always uses the Windows PDF renderer for these, never the Edge previewer. An older file saved without that option shows the information card.
    PDF
    One page at a time. Use the mouse wheel or the arrow buttons in the header to change page. In the pages drawn by Windows, the header also has Fit page (the default), Fit width, 100 percent, Zoom out and Zoom in, and the footer readout shows the page and the zoom, for example "Page 2 of 9 · 125%". With the default setting, Interactive, Peekee tries three ways in this order: the Microsoft Edge PDF previewer, another PDF previewer you have installed, and the PDF renderer built into Windows. With As images it uses the Windows renderer at once, which is faster and lighter but has no links, forms or text selection. Hold Ctrl and turn the wheel to zoom the built-in renderer, and double-click to return to the whole page.
    Word, Excel, PowerPoint and email
    These show through the preview component that Windows or Office installs, the same one File Explorer uses in its preview pane. Peekee bundles nothing for them. If no component is installed for a type, you get the information card. A file that came from the internet is not given to these components, and a PDF from the internet is drawn by the Windows renderer, until you right-click the file, choose Properties and tick Unblock.
    Anything else
    The information card: the name, type, size and date of the file.

    05Settings

    Open Settings from the tray menu. Changes apply at once. There is no Save button. The list on the left shows Peekee with the Markticulous plate and the version at the bottom, on every page. Click the plate to open the About page.

    General
    Open the preview with is Space, Ctrl + Space or Shift + Space. Space also closes the preview, and Esc always does. If another Markticulous app already uses the combination, a warning under the setting says so; you can still choose it. Work in Open and Save dialogs lets Peekee preview inside the file dialogs of other programs. Start with Windows opens Peekee in the tray when you sign in. Check for updates automatically lets Peekee look for a newer version (see Your privacy), and Check now looks straight away. Restart to update is greyed out until an update has been downloaded.
    Preview
    Window size sets how much of the screen a preview takes at first, from 30 to 90 percent. Remember the size I drag the window to keeps the size you chose by dragging an edge, and Forget the remembered size goes back to the setting above. Show the line at the bottom turns the footer (type, size, date) on or off. Images open is Fitted to the window or At 100 percent. Background behind pictures is the colour that fills the preview behind pictures, SVG files and the pages drawn by the Windows PDF renderer. Choose the window colour (light or dark with the theme, and the default), white, light grey, neutral grey (18 percent), dark grey or black. Show a checkerboard behind transparent parts (on by default) puts a checkerboard under the picture itself, so transparent areas show; with it off they show the background colour. An SVG with the checkerboard off and the window colour chosen keeps an automatic light or dark card. PDF files is Interactive (Edge or an installed previewer first) or As images (pages drawn by Windows). Under Text, Font size and Largest file shown (1, 2, 5, 10 or 20 MB) control text and code files. Larger files show their first part only. Extra picture formats adds Peekee's own reader for JPEG XL and AVIF pictures, which Windows cannot open without an extension from the Microsoft Store. Click Add to download it (1.4 MB); nothing is downloaded until you do. Remove deletes it again. Peekee checks the download against a fingerprint it carries and does not use a file that does not match.
    About
    The Peekee name drawn as a wordmark beside the app icon, the version, Open data folder (where Peekee keeps its settings), the support section (see Support Markticulous) and the credits.
    User Guide
    Opens this guide in your web browser. It is always the last item in the list.

    06The tray icon

    Peekee lives in the notification area, next to the clock. Right-click its icon to open the menu.

    Restart to update
    Appears at the top once an update has been downloaded. Choosing it restarts Peekee on the new version.
    Settings…
    Opens the Settings window.
    Start with Windows
    A tick means Peekee starts when you sign in. Click it to turn this on or off. It is the same setting as on the General page.
    ♥ Support Markticulous
    Appears only after you have used Peekee for a while (see Support Markticulous).
    Quit
    Closes Peekee. Start it again from the Start menu.

    Peekee follows the Windows light or dark setting.

    07Other file managers

    Peekee can watch File Explorer and the Desktop by itself. A file manager it cannot watch can ask the running Peekee for a preview in one of two ways.

    From the command line

    Run Peekee.exe with the path of a file. The Peekee that is already running shows it:

    Peekee.exe "C:\Pictures\holiday.jpg"

    Through the named pipe

    Write one line to the named pipe \\.\pipe\Peekee. The commands are:

    preview <path>
    Shows the file.
    toggle <path>
    Shows the file, or closes the preview if it is already open.
    close
    Closes the preview.

    For example, from PowerShell:

    $pipe = New-Object System.IO.Pipes.NamedPipeClientStream('.', 'Peekee', 'Out'); $pipe.Connect(1000); $w = New-Object System.IO.StreamWriter($pipe); $w.WriteLine('preview C:\Pictures\holiday.jpg'); $w.Dispose()

    08Your privacy

    Peekee works only on your PC. It reads the file you select, shows it, and sends nothing about it anywhere. It has no ads and no tracking.

    The only things that use the internet are ones you start or turn on: the update check, which asks GitHub whether a newer version exists when Check for updates automatically is on, and the links to Ko-fi and the support page, which open in your browser only when you click them. If you tell Peekee you have supported Markticulous and use the check, it sends a scrambled version of your email (a hash), and nothing else (see Support Markticulous).

    09Support Markticulous

    Peekee is made by one person who cares about the details. It will always be free. It has no ads and no tracking. If it saves you time, you can help keep it going with a coffee on Ko-fi.

    You will always find the support button under Settings → About, next to a link that explains why these apps are made. After you have used Peekee for a while, an extra item also appears in the tray menu.

    Peekee may ask you for support once in a while, after you have peeked at many files. It asks at most a few times, a long time apart, and never while a preview is open. If you ask it not to ask again, that is final. It will never ask again, and the tray item goes away.

    If you have supported Markticulous, you can tell Peekee on the About page. You then get a small thank-you picture of your choice, called an adornment, shown beside the version number.

    When you tell Peekee you have supported, it asks for the email you used on Ko-fi. Peekee sends only a scrambled version of that email (a hash) to check it, and only when you click Check. Nothing else is sent. If you would rather not, click Skip the check: Peekee takes your word for it.

    10Installing and updating

    Installing

    Run the Peekee setup. It installs for your own account and does not need an administrator. Peekee then starts and puts its icon in the tray. Turn on Start with Windows in Settings if you want it ready every time.

    Updates

    When Check for updates automatically is on, Peekee checks about half a minute after it starts, and then once a day. A newer version downloads in the background, and Restart to update appears in the tray menu and on the General page. Nothing restarts until you choose it. Check now looks straight away. The version you have is on the About page.

    Uninstalling

    Remove Peekee under Settings → Apps → Installed apps in Windows, the same as any other program.

    11If something goes wrong

    Space does nothing
    Check that a file, not empty space, is selected, and that the file list has the keyboard focus: click the file once. Check that Peekee is running (look for its icon in the tray) and that the key in Settings is the one you are pressing. In an Open or Save dialog, make sure Work in Open and Save dialogs is on, and see Where Peekee works about older dialogs.
    I see a card with the name, type and size instead of the file
    Peekee has no way to draw that kind of file. For Word, Excel, PowerPoint and email files it means no preview component is installed for that type. Press the Open button in the header to open the file in its own program.
    A PDF looks different from one in Edge
    If neither the Edge previewer nor another PDF previewer is available, Peekee falls back to the renderer built into Windows. It shows the pages as pictures, one at a time.
    A text file is cut short
    The file is larger than Largest file shown on the Preview page of Settings. The footer says so. Raise the limit if you want to see more.
    The preview is the wrong size
    Drag an edge to resize it, or use Forget the remembered size on the Preview page to go back to the size set there.
    Something else
    Quit Peekee from the tray menu and start it again. If the problem stays, tell Mark through the support page linked above.
