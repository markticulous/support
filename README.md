# Markticulous support page

The support page for my free apps: [Clipee](https://github.com/markticulous/Clipee), [Deskside Radio](https://github.com/markticulous/deskside-radio), and the ones still being built. It is served at **https://markticulous.github.io/support/**.

The apps are free, with no ads and no tracking, and nothing in them is locked. The page links to a [Ko-fi](https://ko-fi.com/markticulous) page for anyone who would like to chip in. Nothing is sold here.

- `index.html`: the page.
- `supporters.json`: names of supporters who chose to be listed.
- `assets/`: logos, wordmarks and the Fraunces font (SIL Open Font License, see `assets/OFL-Fraunces.txt`).
