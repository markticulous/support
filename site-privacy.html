Website Privacy Policy

Last updated: November 13, 2026

← Back to Apps Hub

In short: This website has no accounts, no ads, no analytics and no cookies of its own. When you open the home page, your browser also asks GitHub for the current version numbers and asks Ko-fi for the donation button. Those companies see your address when that happens. We do not collect anything about you.

Who runs this website

This website is run by one person under the name Markticulous. In this policy, "we" means Markticulous. It is the home page for our free apps. This policy covers the website only. Each Windows app has its own privacy policy.

What we collect

Nothing. The pages have no sign-up, no forms, no analytics script and no advertising. We do not keep a log of who visits. We do not know who you are or which pages you read.

The one thing we can see is a count of how many people visited each app's page on GitHub, described below under "Visitor counts". It is a total, not a list of people.

Where the website is hosted

The website is hosted by GitHub Pages, a service of GitHub, Inc. When you open a page, GitHub receives your IP address and the usual details a browser sends, such as the page you asked for and the type of browser. GitHub may keep these in its own logs, under its own privacy statement: GitHub General Privacy Statement. We do not receive those logs.

Other sites your browser contacts

These are every request the home page makes to another address. Everything else on our pages, including the fonts, pictures, the Clipee overview video and the User Guides, is served from this website itself.

  • GitHub, for version numbers. Next to each live app, the home page shows its current version. To get it, your browser asks api.github.com for the latest release of that app, once per app (Clipee, Backee, Peekee and Deskside Radio). Your browser keeps the answer for the rest of that visit in its session storage, so it does not ask again until you close the tab. GitHub sees your IP address, as with any request.
  • Ko-fi, for the donation button. The "Support me on Ko-fi" button is drawn by a script that your browser loads from storage.ko-fi.com. That script and its pictures come from Ko-fi. The script also asks Google (fonts.googleapis.com) for a font stylesheet. Ko-fi and Google therefore see your IP address when the home page loads, before you click anything. They handle that under their own policies: Ko-fi and Google. If your browser does not run scripts, the page shows a plain link instead and makes none of these requests.
  • Links you click. The download buttons, the Ko-fi link and the other links on a page go to GitHub, Ko-fi or other sites only when you click them. After that you are on their site, under their rules.

We do not use a cookie or tracking service to follow you from one of these sites to another.

Cookies and stored data

Our pages do not set any cookies and do not use local storage. The only thing they keep in your browser is the version numbers described above, in session storage, which your browser clears when you close the tab.

The sites listed above, GitHub, Ko-fi and Google, may set their own cookies or store data in your browser under their own policies. We do not control that.

Thank you list

The home page can show a list of supporters who chose to be named. The names are kept in a file on this website (supporters.json) and are read from there when the page opens. Each name is added by hand, only for a supporter who chose to be listed on Ko-fi. The list holds names only: no emails, amounts or messages. If you are on it and want to be removed, write to us and we will remove you.

Visitor counts

Once a day, an automatic job on GitHub asks GitHub for the number of unique visitors to each app's page on GitHub over the last 14 days, and saves those four numbers in a file on this website (stats.json). These are totals about the apps' GitHub pages, not about this website, and they hold no names, addresses or other personal data. GitHub collects the underlying figures itself.

The home page shows these numbers, together with the download counts GitHub publishes, only when it is opened with ?n added to the address. That view is meant for us. The file is part of the public website, so anyone can read the same totals.

Google site verification

The website contains one small file, googled89d387025f2d5b4.html, with a single line of text. It lets Google confirm that we own the site. It collects nothing from visitors.

The supporter check

This website does not use it. Some of our Windows apps can check whether you supported us on Ko-fi, only when you type your email and click Check. What is sent and kept is described in each app's privacy policy.

If you email us

If you write to the address below, we receive your email address and what you send, and we use them only to reply. We do not add you to any list.

Children

This website is not aimed at children, and since it collects nothing, it collects nothing from children either.

Changes and contact

If this policy changes, the new version will be posted on this page with a new date at the top.
