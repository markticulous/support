Clipee Privacy Policy

Last updated: November 13, 2026

In short: Clipee collects nothing about you. It has no accounts, no analytics, no crash reports and no ads. Your clipboard history stays on your PC, in an encrypted file. The only things Clipee ever sends over the internet are a check for new versions of Clipee and, if you ask for it, the supporter check.

Who makes Clipee

Clipee is a free clipboard manager for Windows, made by one person under the name Markticulous. In this policy, "we" means Markticulous.

What we collect

Nothing. Clipee does not send us your clipboard history, your snippets, your settings, your usage or any information about your PC. It has no telemetry and no crash reporting. The only network connections it makes are the two described below: the update check, and the supporter check, which runs only if you click Check.

What Clipee keeps on your PC

Clipee watches the Windows clipboard and saves what you copy, so that you can find and paste it again. By default that is everything you copy, except the items listed under "What Clipee does not save". For each item it keeps:

  • the text, or the picture (and a small preview of it), and any formatting that came with it (rich text or HTML);
  • the name of the program you copied it from, such as chrome;
  • when you copied and last used it, and whether you pinned it.

Your snippets, the text shortcuts you write yourself, are kept in the same place. If you choose to read the text in a picture (OCR), the text it finds is copied to your clipboard and then saved as a new item like any other copy.

Everything lives in the folder %AppData%\Clipee:

  • clipee.db, your history and snippets;
  • key.bin, the key that unlocks the history, protected by Windows (DPAPI) so that it can be read only by your Windows account;
  • settings.json, your settings, such as your shortcut keys, the apps you told Clipee to ignore and the backup folder. It is a plain file and is not encrypted;
  • error.log, technical details of any problem Clipee ran into, kept on your PC and never sent anywhere. It is replaced by a fresh file once it grows past 1 MB;
  • your own sound files, if you picked custom sounds, and the backup password (backup.key), also protected by Windows.

Clipee also writes the shortcut keys it uses to a small shared file in %LocalAppData%\Markticulous, which the Markticulous apps read so that they can warn you when two of them want the same keys.

How the history is protected

The history file is encrypted with a random key that Clipee makes on your PC the first time it runs (SQLite3 Multiple Ciphers, in the SQLCipher 4 format). That key is stored protected by Windows for your account. This keeps the history unreadable if someone copies the file to another PC or account. It does not hide it from programs that are already running as you on your PC, because those can ask Windows for the same key.

What Clipee does not save

  • Copies marked private. Most password managers mark what they copy as private. Clipee skips those. This is on by default and is a switch in Settings, under Privacy.
  • Things that look like keys and tokens. Clipee skips text that looks like an API key, an access token or a private key. This is on by default and is a switch in Settings, under Privacy. It works by pattern, so it can miss some.
  • Apps you ignore. In Settings, under Privacy, you choose programs whose copies are never saved.
  • Everything, while paused. You can pause capture at any time.
  • Very large copies. Text over about 4 million characters and pictures over about 10 MB are not kept.

How long it is kept, and how to delete it

  • Automatic clean-up. Unpinned items older than the number of days you set (30 by default, from 1 to 365) are deleted, and so are the oldest ones beyond the number of items you set (1,000 by default, from 100 to 5,000). This runs when Clipee starts and every six hours. Items you pinned are never removed by the clean-up.
  • Delete one item. You can delete any single item from the popup.
  • Delete history. Settings, under History, has a Delete history button. It deletes the unpinned items, or the pinned ones too if you choose, and then compacts the file so that the deleted text is not left behind inside it. Your snippets are not deleted by this.
  • Remove everything. Close Clipee and delete the folder %AppData%\Clipee. Uninstalling Clipee may leave that folder in place.

Backups

Backups are off until you turn them on. When on, Clipee saves a copy of your history and settings as a .clipeebak file, encrypted with a backup password that you choose, in the folder you pick (by default Documents\Clipee Backups). If that folder is inside a folder that another program syncs, such as OneDrive, that program will copy the backup file too. Clipee itself never uploads it. If you lose the backup password, the backup cannot be opened.

Reading text in pictures (OCR)

When you ask Clipee to read the text in a picture, it uses the text recognition built into Windows, on your PC. The picture is not sent to us or to anyone else.

Update checks

If you installed Clipee with its installer, it checks for a newer version by contacting GitHub, at github.com/markticulous/Clipee, where the updates are published. It checks about 30 seconds after Clipee starts and then at most once every 24 hours. The "Update automatically" switch in Settings turns this off, and the Check now button still works when you press it. If a newer version is found, Clipee downloads it from GitHub and installs it when you restart.

The check is a normal web request made by the Velopack update library, so GitHub sees your IP address, as with any visit to a web page. Clipee adds nothing about you, your clipboard or your settings to it. GitHub handles that under its own privacy statement.

Other connections

Apart from the update check and the supporter check below, Clipee makes no network connections. It opens a web page, such as the User Guide, Ko-fi or a web address you copied, only when you click a link or choose to open it, and then your browser loads it as usual. A copied address is opened only if it is a plain web address.

Supporter check

If you have supported Markticulous on Ko-fi, you can tell Clipee so by typing the email you used there and clicking Check. Clipee then sends a scrambled version of that email (a SHA-256 hash) to support.markticulous.com and receives a yes or no. It never sends the email itself, your name, or anything about your clipboard, and it does not keep the email you typed. Nothing is sent unless you click Check, and you can skip the check entirely.

That server receives a notice from Ko-fi for each payment and keeps only the same kind of hash, the date of the first payment and a count. It keeps no names, amounts, messages or payment numbers. It sees your IP address when you click Check, and uses it only to limit how many checks one address can make in a minute.

Children

Clipee is not aimed at children, and since it collects nothing, it collects nothing from children either.
